# Sovereign · World Society Simulator

A living multiplayer society across 17 countries. Found companies, trade stocks, run for president, form alliances, declare war, negotiate peace, shape policy, and build a global legacy.

**Netlify:** https://sovereign-society.netlify.app

Multiplayer syncs over MQTT (public EMQX broker).

## Play

Open `index.html` or the Netlify URL. Pick a citizen name and starting country.
